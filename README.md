# Frenky14

Based in Slovenia. I work on Shopify and e-commerce, websites and web apps, and AI-powered tools and automation.

## What I work on

### Shopify & e-commerce

Storefronts, customizations, and integrations that connect a shop with the data and services it needs. My work includes bringing external data into Shopify pages and making it useful to visitors.

### Websites & web apps

Building and maintaining web projects, from the pages people interact with to the services behind them. Hosting, deployment, and keeping projects organized are part of that work too.

### AI & automation

Using AI as part of the building process and exploring where automation can reduce repetitive work. This includes experimenting with reusable skills, tools, and workflows for everyday tasks.

## How I use GitHub

A place to develop projects, keep track of changes, and organize reusable resources. Much of that work lives in private repositories, so this profile is an introduction rather than a complete portfolio.
